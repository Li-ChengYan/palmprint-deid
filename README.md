# Palmprint-DeID

Official implementation of **"Palmprint De-Identification via Diffusion Model for High-Quality and Diverse Synthesis"**.

## Overview
This repository contains the code for palmprint de-identification based on a pre-trained diffusion inpainting framework with semantic-guided embedding fusion and prior interpolation.

## Status
The repository is being organized for public release. More code, instructions, and pretrained models will be added soon.
